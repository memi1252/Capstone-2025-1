# 🚀 AstralOutlaw

> **2419년, 마지막 우주선이 운석에 충돌했다. 당신은 살아남을 수 있는가?**

<br>

## 🌌 스토리

**2419년.** 자원이 고갈된 지구를 떠나 인류는 새로운 행성을 향해 이주를 시작했다.

당신은 **마지막으로 지구를 떠난 우주선**의 승객이었지만,  
예상치 못한 **운석 충돌**로 인해 고립된 우주정거장에 홀로 갇히게 된다.

부서진 우주선, 텅 빈 정거장, 그리고 미지의 우주.  
**살아남아, 탈출하라.**

<br>

## 🎮 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 우주 생존 탐험 어드벤처 |
| 배경 | 2419년, 고립된 우주정거장 |
| 목표 | 아이템 수집 → 우주선 수리 → 다른 행성으로 탈출 |
| 플랫폼 | PC (Windows) |
| 엔진 | Unity |

<br>

## ✨ 주요 특징

### 🔧 아이템 수집 & 조합
정거장 곳곳에 흩어진 부품과 재료를 수집해 수리 도구를 직접 제작합니다.  
무엇을 어떻게 조합하느냐에 따라 생존 전략이 달라집니다.

### 🛸 탐험 & 수리
부서진 우주선 각 구역을 탐험하며 손상된 부품을 하나씩 복구해나갑니다.  
새로운 구역을 개방할수록 더 많은 비밀과 위험이 기다립니다.


### 🌑 디스토피아 우주 분위기
황폐한 미래 우주정거장을 배경으로 한 긴장감 넘치는 분위기와  
몰입감 있는 비주얼로 세계관을 표현합니다.
